# AGENTS.md — 我的 AI Agent 学习环境（fork 专用）

这个仓库对别人来说是「微软 AI Agents for Beginners 课程教材」，但对**我**来说它同时是我的**带教材的笔记本**：我在这里边看视频、边跑代码、边记笔记。所有个人产物都集中在 `my-notes/`，与上游教材（`00-*` ~ `18-*` 各 lesson 目录）物理隔离。

## 一、这个学习项目的目标（为什么 fork 它）

我是一名 AI Agent 架构学习者，目标是**高效掌握 Agent 原理与工程实践**。原则：**不深钻论文，重实战与架构理解**。

- **主线交付**：掌握 Agent 开发的 **80% 通用解法**（编排 Orchestration 与记忆 Memory），并见识 **20% 的极致优化**（高并发与标准化评估），最终能向他人清晰解释 Agent 架构的优劣。
- **学习路径**：微软课程（15+ 课，本仓库）→ 剖析开源框架 **DeepSeek-Harness**（侧重科研评估与高并发场景，代码在 `~/Projects/deepseek-harness`，本仓库不做）。

> 我的学习方向是具身智能/科研 Agent 方向，所以「评估」与「高并发」不是泛泛了解，而是要能对接后续科研工作流。

**核心纪律：**

- **根目录官方 `AGENTS.md` 不要覆盖**。它是微软写给贡献者/开发者的；我的学习偏好写在本文件，两者共存。
- 上游更新时：`git pull upstream main`（fork 与上游差异仅在 `my-notes/`，冲突面极小）。
- 将来课程学完，把 `my-notes/` 整体迁入我的个人笔记仓库 `~/Projects/Learn/agent/`（学习产物最终归档处）。

## 三、学习执行流程 ——「三遍法」（我学每课的固定节奏）

不求学全 15 课，但求精。每课按以下三遍推进，AI 协助时按此节奏引导：

1. **第一遍 · 看视频建骨架（1.5 倍速）**
   - 忽略代码细节，只看架构图与流程图。
   - 目标产物：在脑中建立该课的「模块地图」——感知 / 规划 / 记忆 / 行动。
2. **第二遍 · 跑代码填血肉（只挑核心 3-4 节精做）**
   - 优先聚焦四节：**工具调用 Tool Calling**、**Agentic RAG**、**多智能体协作 Multi-Agent**、**状态机（LangGraph）**。
   - **必须执行**：跑通代码后，强制我修改**提示词 Prompt** 或**更换 API**（如 OpenAI → 国产模型），观察 Agent 行为变化，理解「胶水层」逻辑。
3. **第三遍 · 画草图做减法**
   - 让我凭记忆手绘 Agent 核心运行时序图（输入 → LLM 决策 → 工具执行 → 记忆读写）。
   - 针对我画不出的薄弱点，安排针对性复习。

## 四、核心「认知纠偏」指令（教任何代码时必须反复强调）

- **警惕确定性陷阱**：微软课程偏「确定性工作流」（如状态机）。AI 必须时刻提醒我：
  > 「若 LLM 此时输出格式错误或陷入死循环，当前架构如何兜底？」
- **本质论**：无论框架多复杂，内核永远是 `Prompt -> LLM -> Parse -> Execute` 的循环。学每段框架代码时都主动把它归约到这个循环上。

## 五、笔记风格偏好（写进 my-notes/ 时遵循）

- **语言**：中文为主；技术词保留英文原文（首次出现可附中文译名）。
- **体例**：散文式完整段落 + 连词补全（因此/于是/换句话说/作为对照），不要压缩过度的 bullet 索引体。关键段落可用 `*` 平行列举、`1. 2. 3.` 表示推理链。
- **可读性**：每个概念**首次出现自带一句解释**；数字放进可读句式（「从 59.6 单调升到 64.5」），不要裸罗列。
- **结构标记**：每个主题可用 **Core Idea / Goal** 开头 → 问题 → 失败尝试 → **Key Idea** 叙事 → 结论 **Conclusion**。公式用 LaTeX（`$...$` / `$$...$$`），公式后附 `where:` 符号表 + 一句直觉。
- **保留勘误痕迹**：我理解反了又纠正的地方（「我最初理解反了…」）要保留，二刷有价值。
- **跟随用户节奏**：只记录**我自己**提供/已学的内容，不超前生成我还没学的知识；勾选「已学完/已复现」checkbox 前，确认我真的完成了。
